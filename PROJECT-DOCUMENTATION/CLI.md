# What is CLI (Command Line Interface)

A CLI stands for <span style="color:lightblue;">Command Line Interface.

It is a way of interacting with a computer program by typing text commands into a terminal or console, instead of using a graphical interface (like buttons, menus, or windows).

## Key Points about CLI

- **Text-based interface** (no mouse required, only keyboard input).
- Used to run programs, manage files, install software, configure systems, etc.
- Popular among developers, system administrators, and power users because it provides more control, flexibility, and speed.
- Many programming tools and frameworks (like Node.js, Git, Python, etc.) come with their own CLI.

### Examples of CLI commands:

1. In Node.js CLI (REPL):

   ```bash
    $ node
    > console.log("Hello, World!")
    Hello, World!
   ```

2. In Operating System CLI:

   ```bash
       # Navigating folders
       $ cd Documents

       # Listing files
       $ ls   (Linux/Mac)
       $ dir  (Windows)

       # Creating a new file
       $ touch test.txt
   ```

3. A Tool’s CLI (npm):

   ```bash
   $ npm install express
   ```

- #### <p style="color:yellow;">In short, a CLI is a text-based way to communicate with the computer or software by typing commands.</p>
